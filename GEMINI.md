# GEMINI.md — json-3d-renderer

Notes for the Gemini CLI when working in this repository.

The authoritative agent guidance for this repo is [CLAUDE.md](CLAUDE.md). Gemini should
follow the same rules. Key points:

- **Read before writing.** Most files are generated output or vendored libraries — check the
  first line for a `GENERATED by …` banner before editing.
- **Never hand-edit generated artifacts**; their generators live in a separate upstream repo
  (see [docs/known-issues.md](docs/known-issues.md)).
- **No invented commands.** There is no `package.json`, build, or test suite checked in.
- **Large vendored files are opaque:** `concept-tree-3d.bundle.js`, `d3.v7.min.js`.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and
[docs/codebase-overview.md](docs/codebase-overview.md) for orientation.
