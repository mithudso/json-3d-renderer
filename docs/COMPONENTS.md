| Library | File | Stack | Used by |
|---|---|---|---|
| 3D force-directed graph | `concept-tree-3d.bundle.js` (~1.6 MB) | three.js + 3d-force-graph (`ForceGraph3D`) | `examples/concept-tree-3d.html`, `examples/skills-graph*.html` |

## Pages (`examples/`)

### `concept-tree-3d.html` — 3D mind map
- Generated by `scripts/build-concept-tree-3d.py` (upstream; not in repo).
- Inlines data as `const DATA = { nodes: [...], links: [...] }`.
- Panel subtitle reports: **465 backbone nodes · 86 domains · 454 concepts · 3404
  expandable leaves**.
- Controls: search box; layout modes **Radial** (`data-mode="radialout"`), **Tree/top-down**
  (`data-mode="td"`), **Free/force** (`data-mode="null"`); clickable domain chips; node count
  readout; a details panel showing a node's description, source count, and child links;
  click-to-isolate (focus mode) on a node's linked neighbors.

### `concept-tree.html` — 2D views
- Generated by `scripts/build-concept-tree-viz.mjs` (upstream; not in repo).
- Loads `d3.v7.min.js`; renders radial tree / treemap / charts.

### `skills-graph.html` / `skills-graph-full.html` — skills graph
- Node-link graph rendered with the 3D bundle.
- Data: `examples/skills-graph.json` (231 nodes, 800 links) and the larger
  `skills-graph-full.json`.

### Static renderings
- `examples/concept-tree.md`, `examples/tree.md` — hierarchical Markdown.
- `examples/tree-mindmap.md` — Mermaid `mindmap` (generated by
  `scripts/build-concept-tree-mindmap.py`, upstream).

## Data schemas

### Source-tree shape — `examples/tree.json`

A JSON **array** of concept nodes:

```jsonc
{
  "concept":        "A2A Protocol Interoperability", // display name (also the node id)
  "skillId":        "a2a-interop",                   // backing skill slug, or null
  "parentConcept":  "AI Agent Ecosystems",           // parent's `concept`, or null for a root
  "childConcepts":  ["Agent Cards", "..."],           // child concept names (leaves/sub-nodes)
  "researchedAt":   "2026-05-25",                     // ISO date or timestamp
  "sourcesCount":   0,                                 // # research sources backing this node
  "conceptsCount":  10                                 // size metric for the node
}
```

Notes:
- A node is a **root** when `parentConcept` is `null`.
- A node is a **dangling fragment** when its `parentConcept` names a `concept` that does not
  exist in the array — these are real in the current data (see [known-issues.md](known-issues.md)).

### Rendered graph shape — inlined `const DATA` in the 3D page

The generator flattens the tree into a force-graph `{ nodes, links }`:

```jsonc
// nodes[]
{
  "id":            "10gen Repo Intelligence",  // unique; equals `concept`
  "name":          "10gen Repo Intelligence",
  "isRoot":        true,                         // backbone root flag (optional)
  "isGroup":       true,                         // domain/group node vs leaf
  "color":         "hsl(0, 62%, 60%)",          // per-domain color
  "val":           8,                            // node size
  "group":         "10gen Repo Intelligence",   // domain bucket
  "skillId":       "10gen",                      // optional
  "desc":          "…skill description…",        // optional; UNTRUSTED if from external data
  "sources":       0,
  "parent":        null,
  "researchedAt":  "2026-05-25",
  "refreshedAt":   null,
  "conceptsCount": 10,
  "childAll":      ["…"],                          // all child names
  "leaves":        ["…"],                          // expandable leaf names
  "leafCount":     4
}
// links[]
{ "source": "<node id>", "target": "<node id>" }
```

### Skills-graph shape — `examples/skills-graph.json`

```jsonc
{
  "nodes": [
    { "id": "…", "name": "…", "isRoot": false, "isGroup": true,
      "color": "…", "val": 1, "group": "…" }
  ],
  "links": [ { "source": "<id>", "target": "<id>" } ]
}
```
`skills-graph.json` = 231 nodes / 800 links; `skills-graph-full.json` is the larger variant.

## Security note on `desc` / link fields

When a graph is generated from data you don't control, the `desc` and any URL fields are
**untrusted** and must be escaped before being inserted into the DOM, or they become an XSS
vector. See [.github/SECURITY.md](../.github/SECURITY.md).
