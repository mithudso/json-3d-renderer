## Repo-local agents

This repository currently ships no custom agents, hooks, or automation harnesses. It is a
small collection of generated visualization artifacts and vendored rendering libraries; the
work that *produces* those artifacts lives in a separate upstream repo (see
[docs/known-issues.md](docs/known-issues.md)).

If repo-local agents are added later, document each one here using this format:

## General guidance for any agent working here

- Follow the rules in [CLAUDE.md](CLAUDE.md) — especially: do not hand-edit `GENERATED by …`
  files, and do not invent build/test commands that don't exist in this repo.
- Log completed work to [memory.md](memory.md) and the originating request to
  [prompts.md](prompts.md).
